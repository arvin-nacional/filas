# Growth Hero assets

Edit the block in Payload: Pages → your homepage → Layout → Growth Hero → Visuals.
Upload an entrepreneur photo, a fulfillment photo, and up to four marketplace logos.
Media alt text is used by the photos. Card copy, marketplace names, and card visibility
are editable. Headline, description, and both links remain editable in the block.
Empty photo fields use the bundled generated PNGs; no database seed is required.
The photos are separate raster files. Cards, chart bars, icons, and decorative shapes
are independent React/CSS layers, not flattened into the photographs.
